# One-Tap SOS Emergency Assistant

A responsive emergency web application designed for rapid high-stress situation responses.

## Key Features
* **One-Tap SOS Trigger:** 3-second safety countdown ring with visual strobe, haptic feedback, and a Web Audio siren.
* **Live GPS Tracking:** Instant latitude/longitude extraction with Google Maps links ready for quick copy or direct WhatsApp/SMS dispatch.
* **Emergency Contacts:** Local-storage backed contact manager with instant dial (`tel:`) and auto-formatted SMS dispatch buttons.
* **First Aid Guides:** Offline-accessible emergency guides for CPR, choking, and bleeding management.

## Tech Stack
* React & TypeScript
* Tailwind CSS
* Native Web APIs (Geolocation, Web Audio, Vibration, LocalStorage)
